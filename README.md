# Z-PAHUA

Z-PAHUA sewing-pattern storefront.

## GitHub-ready
- `index.html` — website markup and existing JavaScript
- `css/style.css` — extracted CSS
- `js/` — reserved for future JS separation without breaking the current app
- `images/` — local images/assets

## Supabase
The site uses the Supabase publishable frontend key. Never add a service-role/secret key to this repository.

## Run
Open `index.html` locally, or enable GitHub Pages for the repository.
